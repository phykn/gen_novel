# 그래프 건강 탐색

## 역할

이 탐색규칙은 규칙 그래프의 구조 문제가 원고 생성 규칙을 찾는 속도와 정확도를 낮추는 지점을 찾는다.

## 적용 조건

다음 중 하나라도 보이면 그래프 건강 탐색을 수행한다.

- 긴 노드가 늘어 다음 실행에서 가장 이른 원인 노드를 찾기 어렵다.
- 같은 실패가 세 노드 이상에서 같은 문장 구조로 반복된다.
- 둘 이상의 노드가 같은 입력, 같은 판단, 같은 후속 노드를 다루며 역할 차이를 한 문장으로 말하기 어렵다.
- 한 노드가 입력 추출, 실행, 훅 연결, 평가, 탐색 중 둘 이상의 역할을 품는다.
- 노드 사이의 모순, 오래된 판단, 고아 노드, 누락된 링크가 누적되어 현재 합성을 보여주지 못한다.
- 새 대화나 외부 정보에서 얻은 판단이 기존 노드와 연결되지 않아 다음 세대가 같은 내용을 다시 탐색해야 한다.
- 여러 개선이 모두 같은 노드 역할에 몰려 세대 개선이 표면 정리에 머문다.
- 분리와 병합 판단이 [[세대-후보-생성]]의 역할 묶음 기준과 달라 같은 후보가 구조 변경과 생성 보정으로 중복 계산되는 지점.

## 탐색 축

- 라우터 노드가 세부 실행 규칙까지 들고 있어 하위 노드로 넘기는 조건이 흐려지는 지점.
- 실행 노드가 평가기준, 탐색 축, 변이 방식까지 품어 한 파일 한 역할 원칙을 깨는 지점.
- 같은 판단이 여러 노드에 반복되어 더 이른 원인 노드와 후속 역할 노드가 구분되지 않는 지점.
- 유사 노드가 서로 다른 이름으로 남아 다음 실행이 같은 규칙을 두 번 읽게 만드는 지점.
- 분리된 하위 노드가 서로 같은 입력이나 판단을 중복 소유하거나 원래 노드의 필요한 범위를 빠뜨리는 지점.
- 상태 노드가 최근 변경, 다음 우선순위, 오래된 약점을 길게 보존해 실행 노드보다 먼저 읽어야 할 판단을 흐리는 지점.
- 외부 정보가 원천 요약으로 남아 현재 입력 전제에 맞는 실행 판단으로 압축되지 않는 지점.
- 새 대화에서 얻은 판단이 가장 이른 원인 노드 보정으로 합성되지 않고 별도 메모처럼 흩어지는 지점.
- 링크가 빠져 관련 규칙을 찾기 어렵거나, 링크가 너무 넓어 현재 약점과 무관한 노드까지 매번 읽게 하는 지점.
- 라우터 노드가 직접 하위 노드와 손자 노드를 모두 링크해 정해진 경로보다 넓게 읽게 만드는 지점.
- 병합이나 축약이 생성 규칙의 실행 가능성을 낮추거나, 번호 중복이 다음 실행의 읽기 순서를 흐리는 지점.
- 후보 5개를 채우기 위해 같은 문장을 여러 노드에 맞추는 지점.
- 외부 검색으로 넘어갈 약점 문장이 둘 이상의 약점이나 원인 노드를 품어 내부 탐색을 충분히 좁히지 못한 지점.
- 읽기 비용을 줄인다는 이유로 주인공 선택, 선택의 대가, 다음 행동 압력 중 하나를 판단할 문장을 삭제하는 지점.

## 변경 의무

- 그래프 건강 약점을 고른 세대도 상태 갱신만으로 끝내지 않는다.
- 구조 문제를 고를 때는 그 문제가 입력 추출, 중심 선택, 대가 연결, 훅 중 어느 원인 탐색을 늦추는지 함께 확인한다.
- 역할 묶음 기준은 원고 생성 실패의 가장 이른 원인 노드를 더 빨리 찾기 위한 필터로만 쓰고, 구조 정리 자체를 원인 노드보다 우선하지 않는다.
- 먼저 축약, 병합, 링크 정리로 해결할 수 있는지 보고, 부족할 때만 [[노드-경계-정리-방식]]으로 분리한다.
- 구조 변경은 원고 생성 실패를 더 빨리 찾게 만드는 경우에만 통과한다.

## 제한

- 원고 생성 실패 축을 여기서 다시 길게 나열하지 않는다.
- 소설 원고나 후보 목록을 출력하지 않는다.
