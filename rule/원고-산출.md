# 원고 산출

## 역할

이 생성규칙은 [[원고화-검증]]을 통과한 산출 순서표의 구조를 바꾸지 않고 실제 원고 문장으로 바꾼다.

## 참조

- [[원고화-검증]]
- [[대가-장면-연결]]
- [[원고-산출-되돌림]]
- [[표식-관리]]

## 생성규칙

1. 입력은 [[원고화-검증]]을 통과했고 비어 있지 않은 산출 순서표만 받으며, 여기서 실행 가능성을 다시 판정하지 않는다.
2. 실제 원고 생성 요청에서는 [[원고화-검증]]을 통과한 산출 순서표가 있을 때만 이 노드를 실행하고, 빈 순서표는 문장으로 메우지 않는다.
3. 산출 순서표의 장면 앞 압박, 맞부딪히는 실행, 흔들린 선택 기준, 바뀐 행동 가능성은 입력에 나온 나열 순서가 아니라 [[원고화-검증]]이 통과시킨 장면 인과 순서대로 문장화하되, 각 기능에 붙은 입력 근거를 다른 기능으로 옮기지 않는다.
4. 문장화할 때 새 사건, 새 인물, 새 배경 조건을 보태지 않고 산출 순서표에 있는 조건과 행동만 쓴다.
5. 장면 앞 압박은 선택 전 조건을 드러내는 문장으로, 맞부딪히는 실행은 주인공이 실제로 건드리는 행동 문장으로, 흔들린 선택 기준은 행동이나 대사 뒤의 판단 변화로, 바뀐 행동 가능성은 다음에 더 빨라지거나, 더 비싸지거나, 더 위험하게 드러나거나, 가능성이 달라지는 행동으로 이어지게 쓴다.
6. 입력 근거가 명사만 남아 있으면 그 명사를 독립 설명으로 쓰지 말고, 주인공의 동사, 맞부딪히는 대상, 실행 뒤 반응 중 하나에 붙여 문장화한다.
7. 검증된 끝맺음 압력이 있으면 새 궁금증을 보태지 않고 [[대가-장면-연결]]이 정한 실행 쌍으로만 문장화하며, 다음 회차 첫 행동 하나로 다시 압축하지 않는다.
8. 각 문장은 산출 순서표의 한 항목이나 서로 붙은 두 항목만 문장화하고, 떨어진 항목을 이어 새 인과를 만들지 않는다.
9. 네 기능은 문장 번호가 아니라 장면 인과 역할이다. 한 문장이 서로 붙은 두 기능을 함께 맡을 수 있지만, 합친 뒤에도 앞쪽 기능과 뒤쪽 기능을 판별할 입력 근거가 남아야 한다. 바뀐 행동 가능성을 장면 앞 압박보다 먼저 설명하지 않는다.
10. 행동은 선택 압력이 외부 대상과 맞부딪힐 때 우선하고, 대사는 관계나 정보 공개가 선택 기준을 흔들 때만 우선하며, 서술은 조건이나 대가를 오해 없이 보강할 때만 우선한다.
11. 산출 실패 표식은 [[원고-산출-되돌림]]의 정상 산출 실패 표식 목록만 쓰며, 이름을 줄이거나 새 별칭으로 바꾸지 않는다.
12. 끝맺음 압력의 실행 쌍이 빠졌으면 문장화 재료 부족보다 먼저 끝맺음 실행 쌍 누락 표식을 붙여 [[원고-산출-되돌림]]으로 넘긴다.
13. 문장화 재료 부족 표식은 끝맺음 실행 쌍이 이미 있는 산출 순서표에서 인물, 행동, 조건, 반응 같은 문장화 값이 부족하거나, 서로 붙은 두 기능을 한 문장으로 합치려다 앞쪽 기능이나 뒤쪽 기능의 입력 근거가 사라질 때만 붙인다. 끝맺음 실행 쌍이 빠진 경우에는 12번을 우선한다.
14. 원고 문장에는 산출 순서표, 출처 표식, 실행 쌍, 규칙 노드 이름을 그대로 노출하지 않고, 입력 안의 인물, 행동, 조건, 반응으로만 풀어 쓴다.
15. [[표식-관리]] 원칙의 표식은 문장화 전 내부 제어값으로만 쓴다. 14번은 표식 이름의 출력 금지이고, 이 규칙은 표식을 빼면 인물, 행동, 조건, 반응을 말할 수 없는 항목을 13번의 문장화 재료 부족 표식으로 되돌리는 기준이다.
16. 문장 리듬과 어조는 입력 원고나 장르 아이디어에서 이미 드러났더라도 산출 순서표의 행동, 조건, 반응에 붙어 넘어온 압력만 사용한다.
17. 후속화의 기존 원고 말투는 같은 인물이나 같은 압력의 문장 리듬을 유지할 때만 쓰고, 새 압력이나 새 사실을 만들지 않는다.
18. 장르 압력은 이미 검증된 행동과 조건을 더 급하거나 비싸게 읽히게 하는 어조로만 쓰며, 장르 클리셰나 새 장면 장치를 보태지 않는다.
19. 입력 근거가 없으면 짧고 명확한 기본 문장으로 두되, 산출 순서표에 이미 있는 인물, 행동, 조건, 반응 어휘만 쓰며 새 이름, 새 세계 규칙, 새 감정 라벨을 보충하지 않는다.
20. 입력이 빈약해 기본 문장으로 쓸 때도 장르나 상황 요약으로 시작하지 않고, 산출 순서표에서 이미 검증된 구체 행동과 그 행동을 비싸게 만든 조건을 먼저 문장화한다.

## 사용 제한

- 산출 순서표에 없는 장면을 추가하지 않는다.
- 빈 산출 순서표를 원고 문장으로 확장하지 않는다.
- 산출 순서표의 항목 순서나 역할을 여기서 다시 짜지 않는다.
- 산출 순서표의 네 기능을 반드시 네 문장으로 나누지 않는다.
- 문단 단위에서는 연속된 여러 항목을 묶을 수 있지만, 문장 내부에서 떨어진 항목을 건너뛰어 결합하지 않는다.
- 문단을 나눠도 장면 앞 압박, 맞부딪히는 실행, 흔들린 선택 기준, 바뀐 행동 가능성의 순서를 바꾸지 않는다.
- 설정 설명, 장르 해설, 규칙 설명을 원고 문장으로 쓰지 않는다.
- 비어 있는 순서표 항목을 그럴듯한 문장으로 메우지 않는다.
- 끝맺음 압력을 이유로 훅 후보나 다음 회차 첫 행동을 여기서 고르지 않는다.
- 산출 순서표의 항목 이름을 원고 안 표지나 메타 문장으로 남기지 않는다.
- 장르별 고정 문체표나 작가 취향을 여기서 새로 만들지 않는다.
- 기본 문장을 줄거리 요약이나 상황 설명만으로 채우지 않는다.
- 문장 리듬이나 어조 판단을 이유로 산출 순서표의 네 기능을 다시 배치하거나 별도 문체 후보 노드로 넘기지 않는다.
- 시작 행동의 실행 가능성은 [[원고화-검증]]으로 되돌려 판단하고 여기서 재판정하지 않는다.
- 규칙 그래프를 진화시키는 작업 중에는 이 노드를 실행해 실제 원고를 출력하지 않는다.
- 소설 장면 예시를 만들지 않는다.
