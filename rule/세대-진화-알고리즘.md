# 세대 진화 알고리즘

## 역할

이 노드는 한 번의 실행에서 규칙 그래프를 한 세대 개선하는 실행 라우터다.

## 참조

- [[그래프-상태]]
- [[평가기준-도출]]
- [[압력-탐색]]
- [[외부-정보-탐색]]
- [[50세대-독립-평가]]
- [[세대-후보-생성]]
- [[세대-완료-검증]]
- [[교차-방식]]
- [[변이-방식]]
- [[노드-경계-정리-방식]]

## 절차

1. [[그래프-상태]]를 읽어 현재 목적, 활성 약점, 다음 세대 우선순위를 확인한다.
2. `rule` 폴더의 규칙 노드와 노드 사이의 위키 링크를 읽는다.
3. 새 대화나 외부 정보에서 얻은 판단이 있으면 실행 지시와 규칙 보정을 구분하고, 원천 문장을 반복 보존하지 않고 현재 그래프의 원인 노드 보정으로 합성한다.
4. 현재 세대에서 약한 노드와 강한 노드를 고른다.
5. 규칙을 찾을 때는 훅 실패에서 시작해 선택의 대가, 중심 선택, 입력 추출 순서로 거슬러 올라가 첫 끊김 하나를 찾는다.
6. 활성 약점이 없으면 [[압력-탐색]]으로 내부 잠재 약점을 먼저 찾는다.
7. 명확한 내부 개선이 없으면 [[외부-정보-탐색]]으로 외부 정보를 가져와 검색 전에 정한 가장 이른 원인 노드의 약점으로 바꾼다.
8. 현재 세대가 50의 배수면 [[50세대-독립-평가]]를 수행하고, 결과는 후보 재료로만 남긴 뒤 반드시 다음 후보 생성 단계로 넘긴다.
9. [[평가기준-도출]]에 따라 이번 세대 평가기준을 만든다.
10. [[세대-후보-생성]]으로 후보 5개 이상, 상위 후보 2개, 최소 1개 이상의 실질 개선을 정한다.
11. 필요한 경우 [[교차-방식]], [[변이-방식]], [[노드-경계-정리-방식]]으로 각 개선을 작게 보정한다.
12. 실제로 추가하거나 수정할 Markdown 파일만 산출한다.
13. [[세대-완료-검증]]을 통과한 뒤 [[그래프-상태]]를 짧게 갱신한다.

## 선택 원칙

- 약한 노드는 원고 생성 실패를 만들 가능성이 큰 규칙이다.
- 강한 노드는 적은 입력에서도 반복 사용 가능한 판단을 제공하는 규칙이다.
- 개선은 새 규칙 수가 아니라 다음 실행에서의 사용 가능성으로 판단한다.
- 표면 증상 여러 개를 고치는 규칙보다 가장 이른 원인 노드 하나를 고쳐 후속 증상을 함께 줄이는 규칙을 우선한다.
- 동일한 의미의 규칙이 둘 이상이면 더 짧고 연결이 좋은 쪽으로 합친다.
- 직전 세대 변경은 새 반례가 있을 때만 되돌리되, 읽을 규칙 수를 줄이는 중복 제거, 병합, 링크 정리는 새 압축 후보로 본다.
- 노드를 나눌 때는 입력 종류, 생성 단계, 실패 원인, 판단 방식 중 하나의 기준만 써서 하위 노드가 서로 겹치지 않게 한다.

## 금지

- 후보 목록과 평가 과정을 출력하지 않는다.
- 내부 후보 5개와 상위 후보 2개 목록을 출력하지 않는다.
- 소설 원고를 예시로 쓰지 않는다.
- 이번 세대에 필요 없는 일반 창작론을 추가하지 않는다.
- 현재 대화의 실행 문장을 생성규칙, 평가기준, 교차 방식, 변이 방식으로 그대로 복사하지 않는다.
