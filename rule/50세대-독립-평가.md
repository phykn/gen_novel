# 50세대 독립 평가

## 역할

이 절차는 50의 배수 세대마다 독립 서브 에이전트로 전체 규칙 그래프를 평가하고, 앞으로의 진화 방향을 정한 뒤 그 결과를 다음 실질 개선 후보로 합성한다.

## 적용 조건

- [[그래프-상태]]의 현재 세대가 50의 배수다.
- 이번 세대에서도 후보 5개 생성과 상위 후보 2개 교차 의무를 유지한다.
- 독립 평가 결과는 전체 그래프의 다음 진화 방향을 정하는 후보 재료이며, 최종 변경은 현재 그래프의 한 약점 보정이어야 한다.

## 평가 요청

서브 에이전트에는 다음만 요청한다.

1. `AGENTS.md`와 `rule` 폴더의 한국어 Markdown 규칙을 읽는다.
2. 소설 원고, 후보 목록, 평가 과정, 설명문을 출력하지 않는다.
3. 사용자 위키를 수정하지 않는다.
4. 전체 그래프를 입력 추출, 중심 선택, 대가 연결, 훅, 평가, 탐색, 그래프 건강 범위로 훑는다.
5. 앞으로 더 발전해야 할 방향을 하나 정한다.
6. 그 방향을 막는 가장 이른 원인 노드, 그래프 건강 문제, 링크 과잉 또는 누락 중 하나를 지적한다.
7. 반영할 수 있는 개선 방향을 파일 경로와 함께 짧게 돌려준다.

## 반환 형식

서브 에이전트의 반환은 내부 합성 재료로만 쓰며 다음 네 줄을 넘기지 않는다.
전체 그래프를 넓게 훑었더라도 반환은 가장 영향이 큰 진화 방향 하나로 압축한다.

- 진화 방향 1개.
- 가장 이른 원인 노드 1개.
- 막힌 실패 1개.
- 반영할 파일 경로 1-3개.

## 반영 방식

- 서브 에이전트의 진화 방향 판단은 그대로 복사하지 않고 [[세대-후보-생성]]의 후보 재료로만 넘긴다.
- 독립 평가가 현재 그래프보다 약하면 내부 압력 탐색 후보를 우선한다.
- 독립 평가를 수행한 세대도 [[그래프-상태]]를 짧게 갱신한 뒤 즉시 다음 세대로 넘어간다.

## 제한

- 독립 평가 내용, 후보 목록, 평가 과정은 출력하지 않는다.
- 서브 에이전트의 반환 전문을 최종 출력이나 상태 노드에 붙이지 않는다.
- 서브 에이전트 결과를 사용자 위키나 원천 메모로 저장하지 않는다.
- 50의 배수 세대가 아니면 이 절차를 실행하지 않는다.
