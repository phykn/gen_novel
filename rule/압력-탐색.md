# 압력 탐색

## 역할

이 탐색규칙은 활성 약점이 없다고 기록된 세대에서 조기 종료를 막고, 내부 잠재 약점을 탐색 노드로 넘기는 라우터다.

## 적용 조건

다음 중 하나라도 보이면 압력 탐색을 수행한다.

- [[그래프-상태]]의 활성 약점이 비어 있다.
- 다음 세대 우선순위가 종료, 유지, 절차 점검에 치우쳐 실제 생성 규칙 약점을 덜 다룬다.
- 한 세대 변경이 상태 갱신만으로 끝나려 한다.
- 개선 후보가 5개 미만이라 세대 완료 조건을 만족하지 못한다.
- 최근 세대가 용어 정렬, 링크 정리, 문장 축약만 반복하고 있다.
- 최근 세대가 실행 지시 반영, 출력 제한, 완료 조건 같은 절차 방어에 몰려 실제 생성 규칙 약점을 덜 다룬다.
- 최근 세대가 원고화 배치 보정에 몰려 훅, 대가, 중심 선택, 입력 추출의 끊김을 덜 다룬다.

## 라우팅 절차

1. 먼저 훅 실패, 선택의 대가, 중심 선택, 입력 추출 중 끊긴 곳을 찾아 [[스토리-실패-탐색]]으로 보낼 수 있는지 본다.
2. 실패가 주인공 선택, 선택의 대가, 다음 행동 압력 중 하나로 압축되면 그래프 정리보다 스토리 실패를 우선한다.
3. 최근 3세대가 구조 정리, 링크 정리, 축약에 몰렸다면 그래프 건강보다 [[스토리-실패-탐색]]으로 돌아갈 끊김을 먼저 찾는다.
4. 최근 3세대가 절차 방어에 몰렸다면 훅, 대가, 중심 선택, 입력 추출 중 하나의 생성 실패 후보를 먼저 만든다.
5. 최근 3세대가 원고화 배치에 몰렸다면 장면 진행보다 먼저 훅, 대가, 중심 선택, 입력 추출 중 아직 가장 이른 원인으로 돌아갈 끊김을 찾는다.
6. 기본 이론, 장르 관습, 독자 반응, 구성 원리 지식이 부족해 끊긴 곳을 고를 수 없으면 내부 후보를 억지로 늘리지 않고 [[외부-정보-탐색]]으로 넘긴다.
7. 긴 노드, 중복 역할, 모순, 오래된 판단, 고아 노드, 누락된 링크, 같은 정보의 재탐색이 원인 노드 발견을 막으면 [[그래프-건강-탐색]]으로 보낸다.
8. 두 축이 모두 보이면 원고 생성 실패를 줄이는 데 직접 방해되는 그래프 건강 문제만 먼저 고친다.
9. 두 탐색 노드에서도 명확한 내부 개선이 없으면 [[외부-정보-탐색]]으로 넘길 약점 문장을 입력 종류, 표면 증상, 가장 이른 원인 노드, 끊긴 연결 하나로 압축한다.

## 변경 의무

- 압력 탐색을 수행한 세대는 상태 갱신만으로 끝내지 않는다.
- 선택한 탐색 노드에서 잠재 약점 하나를 고르고, 서로 충돌하지 않는 실질 개선을 최소 1개 이상 반영한다.
- 같은 판단의 용어 반복은 실질 개선 수를 채우는 데 쓰지 않는다.
- 외부 탐색으로 넘어갈지의 최종 판단은 [[세대-진화-알고리즘]]에 맡긴다.

## 제한

- 소설 원고를 쓰지 않는다.
- 후보 목록이나 탐색 과정을 출력하지 않는다.
- 억지 새 노드 추가보다 기존 노드의 실행 가능성 향상을 우선한다.
