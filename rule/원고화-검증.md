# 원고화 검증

## 역할

이 생성규칙은 확정된 조건-행동-대가 쌍이 판단 요약이 아니라 원고 문단으로 실행될 수 있는지 확인하고, 문장화 전 산출 순서표까지만 만든다.

## 생성규칙

1. 원고 문단으로 옮기기 직전에는 네 기능을 이름 그대로 나눠 배치한다. 장면 앞 압박은 입력에서 확인된 조건, 맞부딪히는 실행은 그 조건을 건드리는 시작 행동, 흔들린 선택 기준은 실행 뒤 반응이 주인공의 얻기, 피하기, 포기, 비용 판단을 흔드는 지점, 바뀐 행동 가능성은 [[대가-장면-연결]]이 정한 실행 쌍이 다음 행동을 어떻게 더 급하거나 비싸거나 위험하거나 불가능하게 만드는지이다.
2. 검사할 시작 행동은 [[표식-관리]] 원칙의 행동 출처 표식을 함께 가져야 하되, 표식 자체를 장면 조건이나 반응 근거로 쓰지 않는다. [[다음-행동-압축]]에서 넘어온 첫 행동은 다음 회차 첫 장면의 시작 압력으로 받은 값일 때만 검사하고, 보류 후보나 끝 훅 비교 후보에서 온 행동도 현재 중심 선택 실행으로 바꾸거나 대체하지 않는다.
3. 행동 출처 표식이 있어도 시작 행동이 입력에서 확인된 조건을 실제로 건드리지 못하면 통과시키지 않는다.
4. 그 행동은 요약 문장이나 의무 설명이 아니라 입력에서 확인된 인물, 사건, 배경 조건을 실제로 건드리는 최소 실행으로 드러날 때만 통과시킨다. 그 실행이 주인공이 얻으려는 것, 피하려는 것, 포기할 것, 감수할 비용 중 하나를 드러내거나 바꾸지 못하면 다른 행동을 고르지 않고 시작 행동 무효 사유로 표시한다.
5. 입력 근거가 이름, 사건명, 장소명뿐이면 산출 순서표에 그대로 넣지 않고 그 이름이 주인공의 실행이 건드릴 대상, 실행 전 조건, 실행 뒤 반응 중 어느 역할인지 먼저 고른다. 어느 역할도 맡지 못하면 문장화 재료가 아니라 입력 근거 부족으로 낮춘다.
6. 시작 행동은 곧장 대가 설명으로 건너뛰지 않고, 입력에서 확인된 인물, 사건, 배경 조건 중 하나와 맞부딪혀 주인공의 선택 기준을 흔드는 반응을 만든 뒤에만 문단화 통과로 본다.
7. 첫 실행 뒤 반응 없이 대가만 설명되면 새 사건을 붙이지 말고, 그 행동이 실제로 맞부딪칠 조건을 이 노드에서 고르지 않은 채 시작 행동 무효 사유로 표시한다.
8. 시작 행동이 맞부딪힐 조건은 이미 [[추출값-선별]]을 통과한 조건이나 이미 바뀐 조건이어야 하며, 그런 조건이 붙어 있지 않으면 새 장애물을 만들지 않고 시작 행동 무효 사유로 표시한다.
9. 시작 행동이 실행 없이 판단 요약으로만 남거나 선택 기준을 흔들지 못하는 단순 동작으로 남으면 행동 이름을 꾸미지 말고 시작 행동 무효 사유로 표시한다.
10. 시작 행동 무효 사유를 남길 때는 [[원고-생성-절차]]가 되돌릴 수 있도록 행동 출처 표식, 실행 쌍, 빠진 쪽을 함께 유지한다. 빠진 쪽은 맞부딪힐 입력 조건 없음, 실행이 조건을 건드리지 못함, 실행 뒤 반응 없음 중 하나로만 적는다.
11. 이 노드는 무효 사유를 만들 뿐 되돌림 경로를 고르지 않으며, 경로 선택은 [[원고-생성-절차]]가 맡긴다.
12. 행동, 대사, 서술 중 무엇을 우선해도 선택 장면이 닫힐 때는 [[대가-장면-연결]]이 이미 정한 실행 쌍이 있을 때만 끝맺음 압력으로 배치한다. 둘 중 하나가 없으면 새 대가를 찾지 않고, 빠진 쪽과 남은 입력 근거를 붙여 선택 뒤 조건 변화 무효 사유로 표시한다.
13. 원고화 검증을 통과한 뒤에는 새 문장이나 새 장면을 만들지 않고, 장면 앞 압박, 맞부딪히는 실행, 흔들린 선택 기준, 바뀐 행동 가능성을 같은 입력 근거 순서의 산출 순서표로만 묶어 원고 산출 단계로 넘긴다. 이때 산출 순서표는 문장 수나 문장 결합 방식이 아니라 네 기능의 인과 역할과 순서만 정한다.
14. 입력에 드러난 순서가 네 기능의 인과 순서와 어긋나면 입력 근거는 각 기능에 붙인 채 보존하되 산출 순서는 장면 앞 압박, 맞부딪히는 실행, 흔들린 선택 기준, 바뀐 행동 가능성 순서를 우선한다. 이 순서로 배치할 수 없거나 근거가 다른 기능으로 옮겨져야만 연결되면 통과시키지 않는다.
15. 산출 순서표가 비어 있거나 네 기능 중 하나라도 없으면 [[원고-산출]]로 넘기지 않는다. 장면 앞 압박과 맞부딪히는 실행은 앞쪽 기능으로만 묶어 시작 행동 무효 사유로 낮추고, 흔들린 선택 기준과 바뀐 행동 가능성은 뒤쪽 기능으로만 묶어 선택 뒤 조건 변화 무효 사유로 낮춘다. 한 빈 칸을 두 묶음에 동시에 넣지 않으며, 앞쪽 기능과 뒤쪽 기능이 함께 빠지면 인과 순서에서 먼저 비는 앞쪽 기능을 기준으로 시작 행동 무효 사유를 먼저 남긴다. 네 기능은 별도 문장 수가 아니라 산출 순서표 전체에서 맡는 역할로 확인한다.
16. 산출 단계에서 되돌아온 값은 표현 문제가 아니라 산출 순서표의 빈 칸과 끝맺음 실행 쌍 누락만 다시 확인한다. 빈 칸 위치 메모가 있으면 그 메모를 무효 사유 이름으로 복사하지 않고 15번의 앞쪽 기능과 뒤쪽 기능 기준으로 시작 행동 무효 사유나 선택 뒤 조건 변화 무효 사유를 다시 정한다. 실패 표식 판정과 반복 제외는 [[원고-산출-되돌림]]이 맡긴다.
17. [[원고-산출-되돌림]]의 산출 실패 반복 방지 표식이 붙어 돌아온 산출 순서표는 되돌림 메모로만 읽고, 행동 출처 표식, 회차 출처 표식, 시작 행동 무효 사유, 선택 뒤 조건 변화 무효 사유의 이름으로 복사하지 않는다.

## 사용 제한

- 원고화 검증으로 새 사건, 장면 수, 회차별 시작 방식을 다시 고르지 않는다.
- 무효 사유의 되돌림 경로를 여기서 고르지 않는다.
- 빈 산출 순서표를 통과로 처리하지 않는다.
- 검증 통과 뒤 산출 순서표를 만들더라도 실제 소설 문장, 새 장면 내용, 소설 예시를 여기서 쓰지 않는다.
- [[원고-산출]]의 문장화 실패를 문체나 묘사 부족으로 해석하지 않는다.
- 산출 실패 표식 누락을 새 문장 보강 요청으로 해석하지 않는다.
- 산출 실패 반복 방지 표식을 [[표식-관리]]의 공통 표식으로 보존하지 않는다.
- 선택 장면 닫힘 규칙으로 새 대가를 만들지 않고 [[대가-장면-연결]]이 이미 정한 선택 뒤 조건 변화를 원고 위치에 배치하기만 한다.
- 선택 뒤 조건 변화 무효는 [[대가-장면-연결]]이 넘긴 실행 쌍의 누락만 확인한다.
- 관찰 가능한 실행을 만들기 위해 입력에 없는 행동 유형이나 장면 장치를 예시 목록에서 고르지 않는다.
- 맞부딪칠 조건을 만들기 위해 입력에 없는 장애물, 상대, 사건 반응을 보충하지 않는다.
- 새 중심 선택, 선택 기준, 조건 후보를 여기서 다시 고르지 않는다.
- [[다음-행동-압축]]이 고른 첫 행동을 더 그럴듯한 행동으로 바꾸지 않는다.
- 다음 회차 첫 행동을 현재 회차 중간 행동이나 새 행동 후보로 옮기지 않는다.
- 보류 후보나 끝 훅 비교 후보에서 온 다음 회차 첫 행동 출처를 현재 중심 선택 실행 출처로 바꾸지 않는다.
- 행동 출처 표식 없는 시작 행동은 보정하지 않고 시작 행동 무효 사유로만 남긴다.
- 소설 장면 예시를 만들지 않는다.
