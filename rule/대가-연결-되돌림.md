# 대가 연결 되돌림

## 역할

이 생성규칙은 대가 연결 이후 경로에서 돌아온 실패 후보를 새 대가 없이 [[대가-장면-연결]]의 실행 쌍 단위로 복구하거나 제외한다.

## 생성규칙

1. [[첫-행동-후보-정리]]에서 조건만 있거나 행동만 있거나 변화 유형이 빠진 후보가 돌아오면 빠진 짝을 선택 후 조건 변화 사슬에서 한 번만 찾는다. 이 왕복은 [[첫-행동-후보-정리]]와 이 노드 사이에서만 닫힌다.
2. 실행 쌍이 함께 복구되면 [[첫-행동-후보-정리]]로만 되돌리고 [[훅-설계]], [[보류-후보-선별]], [[가능성-검증-행동]] 같은 원천 노드로 재전송하지 않는다.
3. 첫 행동 후보 복구 시도 표식이 붙은 후보가 처음 돌아오면 빠진 짝을 한 번만 찾고, 복구되지 않아 조건만 있거나 행동만 있거나 변화 유형만 남은 상태로 다시 돌아오면 같은 복구를 반복하지 않고 대가 후보에서 제외한다.
4. 첫 행동 후보 복구 시도 표식은 [[첫-행동-후보-정리]]가 붙이고, 이 노드는 그 표식을 읽어 복구 기회가 한 번 남았는지 판단한다. 여기서 표식 이름을 만들거나 다른 되돌림 표식으로 바꾸지 않는다.
5. 되돌림 원인은 빠진 조건-행동-변화 유형 짝, 회차 출처 표식 누락, 행동 출처 표식 누락, 출처 없는 시작 행동 제거, 끝맺음 조건-행동 쌍 누락 중 하나로 구분하고 서로 대체하지 않는다.
6. 회차 출처 표식 누락과 행동 출처 표식 누락만 [[표식-관리]] 원칙의 출처 표식 문제로 다루며, 빠진 조건-행동-변화 유형 짝, 출처 없는 시작 행동 제거, 끝맺음 조건-행동 쌍 누락을 표식 문제로 바꾸지 않는다.
7. [[원고-생성-절차]]에서 행동 출처 표식 누락으로 되돌아온 후보는 이미 있는 조건-행동 쌍 안에서 행동 출처를 한 번만 판정한다.
8. [[원고-생성-절차]]에서 회차 출처 표식 누락으로 되돌아온 후보는 조건이나 행동 내용으로 1화와 후속화를 추정하지 않고, 상위 절차가 보존한 입력 분기 표식이 함께 있을 때만 회차 출처를 복구한다.
9. 보류된 끝 훅 비교 후보의 회차 출처 표식 누락도 입력 분기 표식으로만 복구하고, 끝맺음 조건-행동 쌍 누락으로 바꾸거나 새 끝 후보를 만들지 않는다.
10. 회차 출처나 행동 출처를 한 번 확인한 뒤에도 표식을 붙일 수 없으면 표식 없는 시작 행동은 제거하고, 조건과 대가 중 입력 근거가 남은 값만 복구 대상으로 둔다. 남은 값이 변화 유형만 말하고 행동 이름을 갖지 않으면 복구 대상으로 두지 않는다.
11. [[원고-생성-절차]]에서 출처 없는 시작 행동이 제거되고 조건과 대가만 되돌아오면 새 시작 행동을 보충하지 않고, 그 조건과 대가가 선택 뒤 실제로 더 빨라지거나, 더 비싸지거나, 더 위험해지거나, 가능성이 달라지는 행동을 이미 갖는지 한 번만 확인한다.
12. 다음 회차 첫 행동 출처나 현재 중심 선택 실행 출처가 붙은 시작 행동 무효 사유는 이 노드가 받지 않는다.
13. [[원고화-검증]]에서 선택 뒤 조건 변화 무효 사유가 돌아오면 새 대가를 만들지 않고, 무효 사유에 남은 입력 근거와 빠진 쪽 표시로 기존 실행 쌍 안에서 한 번만 복구한다.
14. [[원고-산출-되돌림]]에서 끝맺음 조건-행동 쌍 누락으로 되돌아오면 새 대가를 만들지 않고, 설명형 대가 제거 규칙을 한 번만 적용한다.
15. 복구되지 않은 후보는 훅 후보로 재전송하지 않고 [[중심-압력-선택]]의 후보 제외 판단이나 대가 후보 제외로 닫는다.

## 사용 제한

- 되돌림을 이유로 새 대가, 새 사건, 새 시작 행동을 만들지 않는다.
- 같은 후보를 같은 경로로 반복 복구하지 않는다.
