# 그래프 관리 평가기준

## 역할

이 노드는 이번 세대 수정이 규칙 그래프의 읽기 비용, 역할 경계, 링크 구조를 개선하는지 판단하는 기준이다.

## 평가기준

- 그래프 관리는 스토리 생성 규칙의 가장 이른 원인 탐색 비용을 줄일 때만 통과한다.
- 표면 증상을 많이 고치기보다 가장 이른 원인 노드를 고쳐 후속 실패를 함께 줄이는가.
- 새 대화나 외부 정보에서 얻은 판단이 매번 다시 유도되지 않도록 현재 규칙 그래프의 지속 판단으로 합성되는가.
- 새 대화의 실행 지시가 그대로 규칙 문장으로 남지 않고 기존 노드의 실패 보정으로 바뀌었는가.
- 원천 정보는 그대로 베끼지 않고, 규칙 노드에는 현재 입력 전제에 맞는 실행 판단만 남기는가.
- 중복 규칙의 삭제, 이동, 병합이 가장 이른 원인 노드와 후속 역할 노드를 더 선명하게 하는가.
- 비슷한 노드를 병합할 때 역할 차이를 한 문장으로 말할 수 없는 노드만 합치고, 입력 종류나 생성 단계가 다른 노드는 유지하는가.
- 긴 노드를 분리할 때 먼저 축약을 시도했는가.
- 분리 뒤 원래 노드와 새 노드가 각각 한 역할만 맡으며 링크와 넘기는 조건이 선명한가.
- 분리된 하위 노드들이 같은 입력이나 판단을 중복 소유하지 않고 원래 노드의 필요한 범위를 빠짐없이 덮는가.
- 다음 세대가 같은 실패를 다시 찾을 때 훑어야 할 노드 수나 문장 수를 줄이는가.
- 라우터 노드는 다음에 읽을 직접 하위 노드만 링크하고, 세부 노드 링크는 하위 노드에 맡기는가.
- 참조와 연결 목록은 본문에서 실제 입력, 출력, 검증, 되돌림 소유권을 만드는 링크만 남기고, 금지나 재전송 차단을 설명하기 위한 링크는 본문 규칙 안에서만 유지하는가.
- [[외부-정보-탐색]]을 쓴 경우 외부 정보가 현재 그래프의 가장 이른 원인 노드 보정으로 압축되는가.
- 노드 사이의 모순, 오래된 주장, 고아 노드, 누락된 링크, 비어 있는 하위 역할이 다음 실행의 탐색 비용을 키우지 않는가.
- 여러 개선을 묶을 때 원인 발견, 정보 추출, 생성 실행, 훅 연결, 평가, 탐색 중 서로 다른 노드 역할을 맡는가.
- 후보 생성 의무와 완료 검증이 절차 본체와 분리되어 다음 실행에서 필요한 조건만 읽게 하는가.
- 번호 정리, 병합, 축약, 역할 단위 노드 분리가 각 노드의 생성 역할을 보존하는가.

## 사용 제한

- 원고 생성 실패 기준을 여기서 다시 길게 나열하지 않는다.
- 줄 수만 줄이고 생성 규칙의 실행 가능성을 떨어뜨리는 변경을 통과시키지 않는다.
- 후보 목록이나 평가 과정을 출력하지 않는다.
