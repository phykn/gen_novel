# 세대 완료 검증

## 역할

이 노드는 한 세대가 상태 갱신만으로 끝나지 않았는지 확인하고 다음 세대로 넘기는 완료 조건이다.

- [[50세대-독립-평가]]

## 무의미한 변경 방지

한 세대 개선은 다음 중 하나 이상을 만족해야 한다.

- 원고 생성 실패 가능성을 줄인다.
- 다음 실행에서 읽을 규칙 수나 중복을 줄인다.
- 길어진 노드를 한 역할 단위로 분리해 다음 실행에서 원인 노드를 더 빨리 찾게 한다.
- 끊긴 위키 링크를 고쳐 다음 실행에서 관련 규칙을 찾게 한다.
- 필요한 생성 실행 규칙을 새로 만든다.

이 중 아무것도 만족하지 않으면 즉시 종료하지 말고 [[압력-탐색]]과 필요한 경우 [[외부-정보-탐색]]으로 후보를 다시 만든다.
새 규칙이 약하면 억지 새 노드 대신 기존 노드 수정, 축약, 병합, 링크 정리 후보를 다시 찾는다.
상태 문구만 다룰 약점이면 [[그래프-건강-탐색]]으로 되돌려 실행 노드의 중복, 누락, 링크 과잉 중 하나를 먼저 고친다.
다시 만든 후보도 이번 세대에서 선택한 약점 하나에 묶어 최종 변경으로 압축한다.

## 완료 조건

- [[그래프-상태]]와 전체 `rule` 노드를 읽었다.
- 활성 약점, [[압력-탐색]]으로 찾은 내부 잠재 약점, 또는 [[외부-정보-탐색]]으로 가져온 외부 압력 하나를 선택했다.
- 선택한 약점이 [[평가기준-도출]]에서 원고 생성 실패와 그래프 관리 실패 중 어느 쪽인지 분류됐다.
- 현재 세대가 50의 배수라면 [[50세대-독립-평가]]를 후보 재료로만 쓰고, 독립 평가 수행 사실이 아니라 실제로 고친 규칙 약점을 `rule` 폴더의 한국어 Markdown 파일과 상태에 남겼다.
- [[세대-후보-생성]]에 따라 후보 5개 이상, 상위 후보 2개, 최소 1개 이상의 실질 개선을 내부적으로 정했다.
- 상위 후보 2개가 하나의 더 이른 원인 보정으로 합쳐진 경우에도 그 보정이 상태 갱신이 아닌 파일 변경이면 실질 개선으로 인정한다.
- 선택한 약점에 대해 추가, 수정, 병합, 축약, 링크 정리 중 서로 충돌하지 않는 실질 개선을 최소 1개 이상 실행했다.
- 실질 개선은 현재 대화의 실행 문장 보존이 아니라 선택한 약점의 원인 노드를 고친 변경이다.
- 원고 생성 실패를 줄이는 변경이라면 주인공 선택, 선택의 대가가 시험할 것, 다음 행동 압력 중 무엇을 더 실행 가능하게 했는지 내부적으로 확인했다.
- 링크를 추가하거나 제거했다면 끊긴 위키 링크와 본문에서 실제 소유권을 만들지 않는 참조 목록 링크가 없는지 확인하고, 있으면 상태 갱신 전에 고쳤다.
- 번호형 목록을 추가하거나 옮겼다면 같은 노드 안의 번호 중복이 읽기 경로를 흐리지 않는지 확인하고, 독립 절차는 글머리표나 별도 표기로 바꿨다.
- 두 노드 이상에 되돌림 경로를 추가했다면 후보를 제거하거나 낮추는 정지 조건이 있는지 확인하고, 단순히 서로 다시 보내는 규칙이면 상태 갱신 전에 고쳤다.
- 외부 이론이나 새 노드를 반영한 뒤에는 링크와 번호 무결성을 확인하되, 점검 결과만으로 세대를 끝내지 않는다.
- [[그래프-상태]]를 최근 변경과 다음 우선순위 중심으로 짧게 갱신했다.

상태 갱신만 한 경우는 한 세대 개선으로 보지 않는다.
