# 원고 산출 되돌림

## 역할

이 생성규칙은 산출 단계가 문장화하지 못한 산출 순서표를 알맞은 소유 노드로 되돌린다.

## 참조

- [[원고화-검증]]
- [[대가-연결-되돌림]]
- [[표식-관리]]

## 생성규칙

1. 산출 단계가 끝맺음 실행 쌍 누락 표식을 붙인 산출 순서표는 문장으로 메우지 말고 [[대가-연결-되돌림]]으로 되돌린다.
2. 산출 단계가 문장화 재료 부족 표식을 붙인 산출 순서표는 끝맺음 실행 쌍이 이미 있는 경우에만 문장으로 늘리지 말고 [[원고화-검증]]으로 되돌린다.
3. 문장화 재료 부족 표식이 붙었지만 끝맺음 실행 쌍이 없으면 정상 표식끼리 충돌한 오표식으로 보고, 표식 이름을 신뢰하지 않고 끝맺음 실행 쌍 누락으로 [[대가-연결-되돌림]]에 보낸다.
4. 이 노드가 받는 정상 산출 실패 표식은 문장화 재료 부족과 끝맺음 실행 쌍 누락뿐이다.
5. 산출 단계가 [[표식-관리]] 원칙의 표식만 남고 인물, 행동, 조건, 반응을 문장화할 수 없다고 표시하면 별도 실패 유형으로 보지 않고 문장화 재료 부족 표식으로 [[원고화-검증]]에 되돌린다.
6. 되돌림이 발생하면 산출 순서표의 통과 상태를 유지하지 않고, 지정된 되돌림 경로에서 다시 검증한 뒤에만 산출 단계를 재시도한다.
7. 산출 실패 반복 방지 표식은 산출 실패 표식 누락, 오표식 보정 시도, 정상 실패 재시도 중 하나만 쓴다.
8. 산출 실패 반복 방지 표식은 이 노드 안에서만 쓰며, [[표식-관리]]에 등록하거나 다른 노드의 공통 표식으로 전파하지 않는다.
9. [[표식-관리]]는 산출 순서표에 남은 회차 출처, 행동 출처, 첫 행동 후보 복구 시도 표식이 문장화 재료가 아님을 확인할 때만 보조 원칙으로 참조한다.
10. 실패 표식이 없거나 정상 산출 실패 표식과 이름이 다른 산출 실패는 산출 순서표 안의 끝맺음 실행 쌍 존재 여부를 보더라도 정상 표식으로 보정하지 않고, 산출 실패 표식 누락이라는 내부 반복 방지 표식으로 표시해 [[원고화-검증]]으로 되돌린다.
11. 산출 순서표의 칸 이름은 장면 앞 압박, 맞부딪히는 실행, 흔들린 선택 기준, 바뀐 행동 가능성만 쓴다.
12. 같은 산출 순서표가 산출 실패 표식 누락으로 다시 돌아오면 반복해서 되돌리지 않고 산출 후보에서 제외하되, 입력 근거가 있는 실행 쌍은 어느 칸이 문장화되지 않았는지만 빈 칸 위치 메모로 붙인다. 시작 행동 무효 사유나 선택 뒤 조건 변화 무효 사유 이름은 [[원고화-검증]]이 다시 정하게 한다.
13. 정상 표식끼리 충돌한 오표식은 오표식 보정 시도 표식을 붙여 3번의 우선순위 보정을 한 번 적용한 뒤 되돌리고, 같은 산출 순서표가 다시 같은 충돌로 돌아오면 산출 후보에서 제외한다.
14. 같은 산출 순서표가 같은 정상 산출 실패 표식으로 다시 돌아오면 정상 실패 재시도 표식으로 보고 같은 경로로 반복해서 되돌리지 않고 산출 후보에서 제외한다.
15. 산출 실패는 훅 강도나 다음 회차 궁금증 부족으로 해석하지 않고, 훅 설계 경로로 되돌리지 않는다.

## 사용 제한

- 문장화 실패를 문체 문제로 낮추지 않는다.
- 문장화 실패 유형을 여기서 새로 판정하지 않는다.
- 실패 표식 없는 값을 두 되돌림 경로 중 하나로 추정하지 않는다.
- 산출 실패 표식을 [[원고화-검증]]의 시작 행동 무효 사유나 선택 뒤 조건 변화 무효 사유로 여기서 바꾸지 않는다.
- 되돌아온 산출 순서표를 여기서 고쳐 통과 처리하지 않는다.
- 표식 이름을 원고 문장으로 풀어 쓰라는 보강 요청으로 바꾸지 않는다.
- 산출 실패를 새 훅 후보 생성 요청으로 바꾸지 않는다.
- 소설 장면 예시를 만들지 않는다.
