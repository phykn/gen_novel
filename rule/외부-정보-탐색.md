# 외부 정보 탐색

## 역할

이 탐색규칙은 웹검색으로 외부 보조 압력을 가져오는 방식이다.

## 적용 조건

다음 조건을 모두 만족할 때만 외부 정보 탐색을 수행한다.

- 현재 대화의 실행 지시는 외부 보조 압력이 아니며 [[세대-진화-알고리즘]]의 원인 노드 보정 절차로만 처리한다.
- [[그래프-상태]]와 전체 규칙 노드를 읽었다.
- [[그래프-상태]]에 바로 다룰 활성 약점이 없다.
- 내부 후보 5개가 모두 용어 정렬, 상태 정리, 중복 문장 정리에 머물러 새 생성 규칙 개선이 선명하지 않다.
- 내부 탐색이 기본 이론, 장르 관습, 독자 반응, 구성 원리 같은 외부 지식 부족 때문에 막히거나, 기존 노드 수정, 축약, 병합, 링크 정리만으로는 선택한 약점의 원인 노드를 충분히 보정하지 못한다.

## 탐색 방식

1. 현재 막힌 약점, 입력 종류, 가장 이른 원인 규칙 노드 하나를 한 문장으로 압축한다.
2. 스토리 실패라면 [[스토리-실패-탐색]]이 고른 입력별 탐색 노드와 끊긴 연결을 함께 적고, 그래프 건강 실패라면 [[그래프-건강-탐색]]이 고른 구조 문제를 적는다.
3. 검색 질문은 그 한 문장을 벗어나지 않게 만들고, 한 번의 검색에서 약점 범주를 늘리지 않는다.
4. 그 약점 문장, 입력 종류, 노드명을 포함하고, 웹소설 연재, 회차 구성, 독자 유지, 장르 기대, 문학 기초 이론, 생성형 글쓰기 중 약점에 직접 닿는 범주만 웹검색한다.
5. 외부 정보는 그대로 규칙으로 복사하지 않고, 현재 그래프의 입력 전제에 맞는 압력이나 실패 가능성으로 바꾼다.
6. 외부 정보는 원천으로만 보고, 규칙 노드에는 출처 요약이 아니라 가장 이른 원인 노드를 고치는 실행 판단만 남긴다.
7. 문학 기초 이론을 가져온 경우에도 이론 이름을 남기기보다 선택 기준, 대가의 인과, 제한 조건, 독자 약속 중 하나로 환산한다.
8. [[문학-기초-환산]]과 함께 쓸 때도 이론 목록을 늘리지 않고, 그 노드가 고른 빈자리 하나를 막는 선택 기준, 인과, 제한 조건, 독자 약속 중 하나만 보강한다.
9. 남길 정보는 주인공 선택, 선택의 대가, 다음 행동 압력 중 어느 연결 실패를 가장 이른 원인 노드에서 줄이는지 한 문장으로 바꿀 수 있어야 한다.
10. 외부 정보가 수정할 원인 노드와 후속 역할 노드를 함께 가리키지 못하면 버리고, 내부 압력 탐색으로 되돌린다.
11. 반영 대상은 검색 질문에 적은 가장 이른 원인 노드를 우선하고, 후속 역할 노드는 그 노드와의 연결 계약이 깨질 때만 함께 고친다.
12. 한 출처의 주장만으로 규칙화하지 않고, 반복 확인되는 압력이나 현재 그래프의 반례로만 남긴다.
13. 풍부한 설정, 고정 평가표, 장면 템플릿, 별도 독자 데이터, 현재 노드와 충돌하는 정보는 후보로 쓰지 않는다.
14. 남은 정보는 [[세대-진화-알고리즘]]의 후보 생성 재료로 넘긴다.

## 반영 제한

- 외부 정보 출처나 검색 과정은 출력하지 않는다.
- 소설 원고나 장면 예시는 만들지 않는다.
- 외부 정보를 현재 그래프보다 우선하지 않는다.
- 외부 출처 자체를 규칙 그래프의 본문으로 보존하려 하지 않는다.
- 외부 정보 때문에 풍부한 입력이 주어진다고 가정하지 않는다.
- [[원고-생성-절차]]를 실행하는 중에는 웹검색을 요구하지 않는다.
