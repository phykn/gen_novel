# 평가기준 도출

## 역할

이 노드는 고정 평가기준 목록이 아니라, 이번 세대의 약점을 평가 노드로 넘기는 라우터다.

## 참조

- [[스토리-생성-평가기준]]
- [[그래프-관리-평가기준]]
- [[압력-탐색]]
- [[외부-정보-탐색]]

## 도출 절차

1. 현재 입력 조건과 [[그래프-상태]]의 다음 세대 우선순위를 확인한다.
2. 약점이 원고 생성 실패라면 [[스토리-생성-평가기준]]으로 넘긴다.
3. 약점이 노드 길이, 중복, 링크, 외부 정보 반영, 역할 경계라면 [[그래프-관리-평가기준]]으로 넘긴다.
4. 기본 요소 약점이 선택 기준, 인과, 제한 조건의 끊김이면 원고 생성 실패로 보고, 용어 누락이나 문서 위치 문제면 그래프 관리 실패로 본다.
5. 둘 다 걸리면 원고 생성 실패를 먼저 평가하고, 그 실패를 줄이는 범위에서 그래프 관리 기준을 적용한다.
6. 탐색 경계 수정이 원고 실패의 가장 이른 원인 노드를 바꾸면 그래프 관리보다 원고 생성 실패 기준을 먼저 적용한다.
7. 그래프 관리 약점이 원고 생성 실패의 가장 이른 원인을 더 빨리 찾게 하지 않으면 후보 우선순위를 낮춘다.
8. 최근 3세대 안에서 해결된 약점은 같은 실패가 다른 노드에서 다시 보일 때만 되살린다.
9. 평가기준은 이번 세대의 규칙 선택과 수정에만 사용한다.

## 사용 제한

- 평가기준 후보나 점수표는 출력하지 않는다.
- 스토리 생성 기준과 그래프 관리 기준을 한 목록에 다시 합치지 않는다.
- 현재 약점과 무관한 기준을 새 의무로 늘리지 않는다.
