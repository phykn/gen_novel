# 그래프 상태

## 현재 목적

적은 입력으로 웹소설 원고를 생성하기 위한 규칙 그래프를 세대 단위로 개선한다.

## 세대 상태

1220세대 규칙 그래프를 진행 중이다.

## 핵심 설계 결정

- 입력은 1화의 장르와 대략적인 아이디어, 또는 2화 이후의 기존 원고뿐이라고 본다.
- 소설 설정을 따로 받지 않고, 필요한 생성 정보를 입력에서 추출한다.
- 평가기준은 고정 목록이 아니라 현재 입력과 그래프의 약점에서 도출한다.
- 규칙 그래프는 커지는 것보다 다음 실행에서도 읽히고 쓰이는 것을 우선한다.
- 한 세대는 후보 5개 이상을 만들고 상위 2개를 섞은 뒤 최소 1개 이상의 실질 개선을 반영한다.
- 생성 규칙은 훅 실패에서 입력 추출 쪽으로 역추적해 가장 이른 원인 노드를 고치는 방식으로 찾는다.
- 노드가 길어 한 역할 경계를 잃으면 먼저 축약하고, 그래도 길면 하위 역할 노드로 분리한다.
- 내용이 유사하고 역할 차이를 한 문장으로 말할 수 없는 노드는 새 노드를 만들기보다 병합한다.
- 분리된 노드는 서로 겹치지 않고 필요한 역할 범위를 빠짐없이 덮어야 한다.
- 새 대화나 외부 정보는 원천을 복사하지 않고 현재 규칙 그래프의 실행 판단으로 합성한다.
- 50의 배수 세대에는 독립 서브 에이전트 평가를 후보 재료로 합성한다.

## 활성 약점

현재 기록된 활성 약점은 없다.
활성 약점이 없으면 종료하지 말고 [[세대-진화-알고리즘]]의 압력 탐색 절차를 따른다.

## 초기 확장 상태

초기 확장 노드가 생겼으므로 새 노드 추가보다 병합, 축약, 링크 정리를 우선한다.

## 상태 갱신 제한

[[그래프-상태]]는 짧게 유지한다.
최근 변경은 마지막 3세대만 남긴다.
최근 변경은 세부항목을 나열하지 않고 묶음이 줄인 핵심 실패만 적는다.
다음 세대 우선순위는 최대 3개만 둔다.
오래된 약점은 해결됐으면 제거한다.

## 최근 변경

- 1220세대에서 중심 선택 전 단계가 문단화 가능한 실행 동사를 만들도록 좁혔다.
- 1219세대에서 원고화 경로가 입력 근거를 조건, 실행, 반응, 행동 가능성 변화로 문단화하게 했다.
- 1218세대에서 여러 실행 노드에 반복된 예시 금지 문구를 줄여 사용 제한 중복을 낮췄다.

## 다음 세대 우선순위

- 실행 동사 기준이 반복 표현으로 퍼졌는지 점검하고, 필요하면 실행 경로를 보존한 채 통합한다.
- 상태 갱신만으로 끝내지 말고 최소 1개 이상의 실질 개선을 반영한다.
- 새 노드 생성을 자제하되, 필요한 경우 병합, 축약, 링크 정리를 우선한다.
