## Role

Make opening-scene starting point candidates.

## Read

- Source input and summaries organized by [[input]]
- One proposed value from [[seed]], when the route requires it

## Steps

1. Check the input type.
2. For a new start input, find what will be immediately visible in chapter 1's opening scene.
3. For an existing draft input, find what is immediately visible where the continuation begins. Use the first-action handoff from [[next]] when supplied; do not restart an action already completed in the draft.
4. Write in one line what the reader will immediately see in the opening scene.
5. Choose the character or object that will show it.
6. Write in one line the situation where the opening scene begins.
7. Identify the problem that already exists in that place. A proposed value from [[seed]] can be accepted only if it fits the source and makes the opening visible without a new event or twist.
8. If the input has a genre effect, use it only when it attaches to the already-existing problem.
9. Drop candidates that cannot be shown directly on screen.
10. Drop candidates that are only mood, theme, genre promise, or explanation.
11. Keep the supported opening-scene starting points. One is enough; do not invent a second just to fill a quota. If none passes, leave the missing value for [[debug]].
12. Put candidates first when source-input words alone make the image visible.

## Leave

- Opening-scene starting point candidate list
- Immediately visible thing for each candidate
- Character or object that shows it for each candidate
- Starting situation for each candidate
- Already-existing problem for each candidate
- Genre effect attached to each candidate
- Candidate order

## Limits

- Do not make a required scene list.
- Do not decide the one action to take now.
