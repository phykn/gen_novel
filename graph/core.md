## Role

Keep the draft tied to the scene values that make prose possible.

## Core

A novel draft does not begin by completing the setting.

It begins by finding what is visible now, what the protagonist must do now, what is lost if that action does not happen, what changes after the action, and what must happen next because of that change.

Treat those values as the working scene hypothesis.
The hypothesis may change while moving through the graph, but unchecked values must not enter prose.

## Working Values

Every drafting node uses values from one of these:

- source input;
- a summary created from source input;
- a candidate created by [[seed]] or [[block]] and accepted by the next node.

Keep the source or accepted candidate for each working value identifiable.
[[result]] may derive consequences from these values without adding unsupported facts.
Do not send unchecked invented action, result, change, or next action to prose.

The immediate next action is still required, not already completed. Its execution and consequences belong to the next scene.

## Failure Paths

A direction fails when:

- genre, mood, or explanation replaces visible scene material;
- the protagonist has no physical action to take now;
- nothing is immediately lost if the action does not happen;
- the action does not change an object, position, relationship, or public state;
- prose fills an empty slot with a new event, setting, character, or twist.

When a failure path appears, return to the node where the missing value first appeared.
