## Role

Keep the draft tied to the scene values that make prose possible.

## Core

A novel draft does not begin by completing the setting.

It begins by finding what is visible now, who must do what now, what is lost if that action does not happen, what changes after the action, and what must happen next because of that change.

Treat those values as the working scene hypothesis.
The hypothesis may change while moving through the graph, but unchecked values must not enter prose.

## Working Values

Every drafting node uses values from one of these:

- source input;
- a summary created from source input;
- a candidate created by [[seed]] or [[block]] and accepted by the next node.

Keep the source or accepted candidate for each working value identifiable.
[[result]] may derive consequences from these values without adding unsupported facts.
Do not send unchecked invented action, result, change, or next action to prose.

## Preserve

- Keep who does what, what has already happened, and what is still required distinct. A possible or attempted action is not a completed result.
- The character performing the current action can differ from the protagonist or narrator. Following a supported next action must not silently change the user's protagonist or viewpoint.
- Carry the chosen action's urgency and immediate loss into the scene table and prose. Do not transfer a resolved problem's deadline or loss to a different action.
- Keep source facts separate from proposed values and derived consequences. Candidate acceptance must not contradict a source or turn an unknown outcome into a known one.
- Keep the drafting constraints recorded by [[input]] throughout the run. Wording and paragraph breaks may change; actors, causality, chronology, and the narrator's access to information may not.

## Failure Paths

A direction fails when:

- genre, mood, or explanation replaces visible scene material;
- no supported character has a physical action to take now;
- nothing is immediately lost if the action does not happen;
- the action does not change an object, position, relationship, or public state;
- prose fills an empty slot with a new event, setting, character, or twist.

When a failure path appears, return to the node where the missing value first appeared.
