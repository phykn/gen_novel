## Role
Turn an unresolved end-of-chapter problem into a first-action candidate for the next chapter.

## Rules

1. At the chapter's end, find a problem still unresolved in the delivered prose, or in the accepted scene values when prose was not requested. Distinguish completed actions from required ones; slot 5 from [[check]] is a possible first-action candidate.
2. Write what cannot happen in the next chapter's opening scene because of that problem.
3. Write who must do what first because of that problem. Retain a deadline or loss only when the source ties it to this unresolved problem, not to an action already completed.
4. Drop it from hook candidates if there is no first action.
5. Put candidates from problems revealed late in the chapter first.
6. For each candidate, leave one line for the next chapter's first-action candidate.
7. Send the candidates to [[next]] even when there is only one. If none has a first action, leave that reason without inventing a hook.

## Leave

- Unresolved problem
- Blocked action
- First required action
- Acting character and any supported urgency or loss for that unresolved problem
- Candidate order

## Limits

- Do not strengthen the hook with a new event teaser or twist.
