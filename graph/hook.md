## Role
Turn an unresolved end-of-chapter problem into a first-action candidate for the next chapter.

## Rules

1. After [[result]] or [[write]], find a problem that is still unresolved.
2. Write what cannot happen in the next chapter's opening scene because of that problem.
3. Write what must happen first because of that problem.
4. Drop it from hook candidates if there is no first action.
5. Put candidates from problems revealed late in the chapter first.
6. For each candidate, leave one line for the next chapter's first-action candidate.

## Leave

- Unresolved problem
- Blocked action
- First required action
- Candidate order

## Limits

- Do not strengthen the hook with a new event teaser or twist.
