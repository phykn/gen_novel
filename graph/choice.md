## Role
Choose one action the protagonist must take now in the opening scene.

## Rules

1. Start with the first candidate left by [[opening]].
2. If the protagonist cannot do any action by hand, move to the next candidate.
3. If there is no reason to do that action now, move to the next candidate.
4. If nothing is immediately lost by not doing it, move to the next candidate.
5. If only thinking, deciding, understanding, or explaining remains, move to the next candidate.
6. Choose one action from the first candidate that passes.
7. If no candidate passes, leave a failure reason for [[debug]].

## Working Value

The chosen action is the current center of the scene hypothesis.
If later nodes cannot produce a visible change from it, return here and choose again.

## Leave

- Protagonist
- Action to take now
- Reason it must happen now
- What is lost if it does not happen
