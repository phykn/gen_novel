## Role
Choose one physical action that must happen now in the opening scene.

## Rules

1. Start with the first candidate left by [[opening]].
2. Identify the acting character from the source or accepted candidate, using the pending action for continuation. If that character cannot take a physical action, move to the next candidate. Keep the protagonist and narrator as recorded by [[input]].
3. If there is no supported reason to do that action now, move to the next candidate.
4. If nothing is immediately lost by not doing it, move to the next candidate. A deadline alone does not establish a loss; do not substitute “the action will not be done” for a consequence.
5. If only thinking, deciding, understanding, or explaining remains, move to the next candidate.
6. Choose one action from the first candidate that passes. Keep its actor, reason, immediate loss, and source or accepted candidate together for [[result]].
7. If no candidate passes, leave a failure reason for [[debug]].

## Working Value

The chosen action is the current center of the scene hypothesis.
If later nodes cannot produce a visible change from it, return here and choose again.

## Leave

- Acting character
- Action to take now
- Reason it must happen now
- What is lost if it does not happen
- Accepted opening candidate and any action candidate from [[block]]
