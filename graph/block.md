## Role
Turn a loose idea into an action that is blocked and an action that must happen.

## Rules
1. Pick one loose idea from the input or accepted opening: genre expectation, setup, possibility, or repeated element.
2. Write what the affected character cannot safely achieve because of it; do not turn a risk into a new physical inability.
3. Derive a required action from that existing problem. Do not add an obstacle, motive, deadline, or loss merely to make the action pass.
4. Drop it if failing to take the action would not cause a supported immediate loss.
5. If it changes the action in the current scene, attach it to that opening candidate for [[choice]] to accept or reject.
6. If it changes the first action of the next chapter, send it to [[hook]] only when it follows from an existing unresolved chapter-end problem.
7. Drop it if it changes neither the current action nor the next chapter's first action.

## Leave
- Loose idea
- Blocked action
- Required action
- Immediate loss if the action is not taken
- Source or opening candidate it belongs to

## Limits
- Do not keep only a lesson, mood, or genre label.
- Do not turn a possibility into a fixed new event or twist.
