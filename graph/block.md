## Role
Turn a loose idea into an action that is blocked and an action that must happen.

## Rules
1. Pick one loose idea: genre expectation, setup, possibility, or repeated element.
2. Write what the protagonist cannot do because of it.
3. Write what the protagonist must do because of it.
4. Drop it if being wrong would not immediately cost anything.
5. If it changes the action in the current scene, keep it as a [[choice]] candidate.
6. If it changes the first action of the next chapter, keep it as a [[hook]] candidate.
7. Drop it if it changes neither the current action nor the next chapter's first action.

## Leave
- Loose idea
- Blocked action
- Required action
- Immediate cost if wrong

## Limits
- Do not keep only a lesson, mood, or genre label.
- Do not turn a possibility into a fixed new event or twist.
