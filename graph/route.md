## Role

Read this first in the `graph` folder and choose the next node to read now.

## Input Assumptions

- New start input may contain only a genre and rough idea.
- Existing draft input may contain only the previous chapter draft.
- Do not assume a separate character sheet, world sheet, setup list, or style guide.

## Main Path

- Source input: [[input]]
- Input files and summary files are organized: [[opening]]
- Opening-scene starting point candidates exist: [[choice]]
- The protagonist's current action is chosen: [[result]]
- The pre-action image and post-action change are chosen: [[check]]
- The paragraph order table passes: [[write]]

## Optional Path

- Source has only genre or idea: [[seed]]
- Genre, setup, or possibility does not lead to action: [[block]]
- An unresolved problem remains at the end of a chapter: [[hook]]
- There are multiple first-action candidates for the next chapter: [[next]]

## Return Path

- Input type judgment failed: [[input]]
- Current action choice failed: [[choice]]
- Pre-action image and post-action change failed to connect: [[result]]
- Find the cause of broken output: [[debug]]
- Cause unknown: [[debug]]

## Limit

- This folder is a draft-generation rule graph.
